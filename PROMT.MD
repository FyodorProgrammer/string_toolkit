# Описание задачи

Реализовать модуль `string_toolkit`, предоставляющий функции:
- `remove_duplicates(s: str) -> str`: удаление дубликатов символов
- `reverse(s: str) -> str`: разворот строки
- `is_palindrome(s: str) -> bool`: проверка на палиндром
