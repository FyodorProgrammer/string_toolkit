# Описание задачи

Создать пакет **string_toolkit** с базовыми утилитами для работы со строками:

* `reverse(text: str) -> str` — разворачивает строку в обратном порядке;
* `slugify(text: str) -> str` — превращает строку в URL‑slug (только [a‑z0‑9‑_]);
* `camel_to_snake(text: str) -> str` — `CamelCase` → `camel_case`;
* `snake_to_camel(text: str) -> str` — `snake_case` → `SnakeCase`.

Каждая функция должна корректно обрабатывать пустую строку и Unicode‑символы.
